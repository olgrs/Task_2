# Stellar Burgers — API-тесты (Задание 2)

Автоматизированные тесты для проверки API сервиса Stellar Burgers (https://qa-stellarburgers.education-services.ru/).  
Проект покрывает основные эндпоинты: создание, логин, изменение данных пользователя, создание заказа и получение списка заказов.

## Тестируемые эндпоинты

- **Создание пользователя** (`POST /api/auth/register`)  
  - успешное создание уникального пользователя  
  - создание уже зарегистрированного пользователя  
  - отсутствие обязательного поля
- **Логин пользователя** (`POST /api/auth/login`)  
  - успешный вход  
  - неверный логин / неверный пароль
- **Изменение данных пользователя** (`PATCH /api/auth/user`)  
  - с авторизацией (изменение email, пароля, имени)  
  - без авторизации (ожидание ошибки)
- **Создание заказа** (`POST /api/orders`)  
  - с авторизацией и валидными ингредиентами  
  - без авторизации  
  - без ингредиентов  
  - с неверным хешем ингредиентов
- **Получение заказов пользователя** (`GET /api/orders`)  
  - авторизованный пользователь  
  - неавторизованный пользователь


## Запуск тестов

1. Установите зависимости:
   pip install -r requirements.txt
2. Запустите все тесты с сохранением данных для Allure:
   pytest tests/ --alluredir=allure-results
3. Просмотрите отчёт локально (если установлен Allure):
   allure serve allure-results

## Особенности реализации
- Независимость тестов: каждый тест использует уникального пользователя, который создаётся перед тестом и удаляется после.
- Фикстуры: new_user создаёт пользователя через API и удаляет его в teardown; auth_token возвращает токен для авторизованных запросов.
- Параметризация: применяется там, где требуется проверить несколько вариантов входных данных (например, изменение разных полей).
- Проверки: каждый тест содержит один assert, проверяющий статус-код и тело ответа.
- Allure-отчёт: все ключевые шаги обёрнуты в @allure.step.

## Требования
- Python 3.12+
- Пакеты: requests, pytest, allure-pytest
